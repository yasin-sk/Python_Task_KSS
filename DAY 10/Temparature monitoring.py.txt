 # . Temperature Monitoring System
A weather station records temperatures for two days.
Scenario:
Day 1: [30, 32, 31]
Day 2: [29, 33, 34]
Task:
● Create a 2D NumPy array to store this data.
● Print the array.
● Find the total temperature recorded.


import numpy as np

# 1. Create a 2D NumPy array for Day 1 and Day 2
temperatures = np.array([[29, 33, 34]])

# 2. Print the array
print("Temperature Array:")
print(temperatures)

# 3. Find the total temperature recorded
total_temp = np.sum(temperatures)
print("Total Temperature:", total_temp)
