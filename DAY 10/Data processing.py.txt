 # Data Processing Pipeline
A data pipeline receives the following array:
[12, 7, 25, 3, 18, 10]
Scenario:
1. Convert the list into a NumPy array.
2. Sort the array.
3. Split the sorted array into two equal parts.
4. Calculate the sum of each part.
Output:
● Sorted array
● Two split arrays
● Sum of each part


import numpy as np

# 1. Convert the list into a NumPy array
raw_data = [12, 7, 25, 3, 18, 10]
data_array = np.array(raw_data)

# 2. Sort the array
sorted_array = np.sort(data_array)

# 3. Split the sorted array into two equal parts
part1, part2 = np.split(sorted_array, 2)

# 4. Calculate the sum of each part
sum_part1 = np.sum(part1)
sum_part2 = np.sum(part2)

# Print outputs
print("Sorted Array:", sorted_array)
print("First Split Array:", part1)
print("Second Split Array:", part2)
print("Sum of First Part:", sum_part1)
print("Sum of Second Part:", sum_part2)
