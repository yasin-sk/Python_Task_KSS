 # Multi-Department Data Aggregation
A company collects employee counts from two branches.
Branch A:
[[10, 20],
[30, 40]]
Branch B:
[[5, 15],
[25, 35]]
Scenario:
● Combine the two matrices.
● Calculate the total employees across all departments.
● Print the combined matrix and total.


import numpy as np

# 1. Store employee counts for Branch A and Branch B
branch_a = np.array([[30, 40]])

branch_b = np.array([[25, 35]])

# 2. Combine the two matrices (element-wise addition)
combined_matrix = branch_a + branch_b

# 3. Calculate the total employees across all departments
total_employees = np.sum(combined_matrix)

# 4. Print the combined matrix and total
print("Combined Employee Matrix:")
print(combined_matrix)
print("\nTotal Employees Across All Departments:", total_employees)
