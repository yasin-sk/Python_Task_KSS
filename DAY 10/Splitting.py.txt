 # Splitting Data for Parallel Processing
A dataset contains the following values:
[5, 10, 15, 20, 25, 30]
Scenario:
You want to distribute the data across 3 processors.
Task:
● Store the data in a NumPy array.
● Split it into 3 equal parts using NumPy.


import numpy as np

# 1. Store the data in a NumPy array
dataset = np.array([5, 10, 15, 20, 25, 30])

# 2. Split it into 3 equal parts
split_data = np.split(dataset, 3)

# 3. Print the split arrays
for i, part in enumerate(split_data, 1):
    print(f"Processor {i} data:", part)
