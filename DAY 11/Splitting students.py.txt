 # Splitting Student Scores Across Servers
A dataset:
[50, 60, 70, 80, 90, 100, 110, 120]
Scenario:
A distributed system needs to divide this data among 4 servers.
Task:
● Convert to NumPy array.
● Split the array into 4 equal parts using array_split().


import numpy as np

# Given list of student scores
scores = [50, 60, 70, 80, 90, 100, 110, 120]
#  Convert to NumPy array
scores_array = np.array(scores)
# Split the array into 4 equal parts using array_split()
server_batches = np.array_split(scores_array, 4)
# Print the split arrays
print("Split list of arrays:", server_batches)
for i, batch in enumerate(server_batches, start=1):
    print(f"Server {i}: {batch}")
