 # Check Data Type of Inventory Values
A warehouse stores product quantities:
[10, 20, 30, 40]
Task:
● Convert it into a NumPy array.
● Print the data type (dtype) of the array.


import numpy as np
# Given list of product quantities
quantities = [10, 20, 30, 40]
# Convert it into a NumPy array
inventory_array = np.array(quantities)
# Print the data type (dtype) of the array
print("Data type (dtype):", inventory_array.dtype)
