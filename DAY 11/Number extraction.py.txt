 # Student Roll Numbers Extraction
A list contains roll numbers:
[101, 102, 103, 104, 105, 106]
Scenario:
You want only the middle students (index 2 to 4).
Task:
● Use NumPy slicing to extract those values.


import numpy as np
# Given list of student roll numbers
roll_numbers = [101, 102, 103, 104, 105, 106]
roll_array = np.array(roll_numbers)
# Extract middle students (index 2 to 4 inclusive)
middle_students = roll_array[2:5]
print("Extracted roll numbers:", middle_students)
