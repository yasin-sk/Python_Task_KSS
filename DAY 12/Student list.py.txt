 # Student List Backup (Shallow Copy)
A teacher has a list of student marks:
marks = [50, 60, 70, 80]
Scenario:
She creates a backup using assignment:
backup = marks
Task:
● Modify the first element in marks.
● Observe the change in backup.
● Explain why both lists are affected.


# Given list of student marks
marks = [50, 60, 70, 80]
# Create a backup using assignment
backup = marks
# Modify the first element in marks
marks[0] = 95
# Observe the change in both lists
print("Modified marks:", marks)
print("Backup list:   ", backup)
