 # Multi-Level List Transformation (Advanced List Comprehension)
A dataset contains:
data = [[1, 2, 3], [4, 5], [6]]
Task:
● Flatten the list using list comprehension.
● Then create a new list containing squares of only even numbers.


# Given nested dataset
data = [[1, 2, 3], [4, 5], [6]]
# 1. Flatten the list using list comprehension
flattened = [num for sublist in data for num in sublist]
# 2. Create a new list containing squares of only even numbers
even_squares = [num ** 2 for num in flattened if num % 2 == 0]
print("Flattened list:", flattened)
print("Squares of even numbers:", even_squares)
