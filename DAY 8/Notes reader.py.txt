  # Notes Reader Program
A student stores daily notes in a file called notes.txt. Write a program that opens the file, reads all the contents, and
displays them on the screen.


try:
    file = open("/tmp/notes.txt", "r")
    print(file.read())
    file.close()

except FileNotFoundError:
    file = open("/tmp/notes.txt", "w")
    file.write("My first note!")
    file.close()
    print("notes.txt created! Click Run again to read it.")
